How to Get an API Key

  1. Register an account at the central management platform
  2. Navigate to "Add pNode" section
  3. Generate a new API key
  4. Copy the API key and paste it above
  5. Save configuration and test connection

Security Notes

  • API key is stored encrypted on this machine
  • Connection uses TLS (wss://)
  • Commands are whitelisted and rate-limited
  • You can revoke access anytime from central dashboard
  • Local Pod-Man continues working if central server is down
